# Как писать пост или статью

Короткий процесс: создать единицу визардом → написать текст → запушить. Сайт
пересобирается автоматически (`deploy.yml` → GitHub Pages); автопостинг в
соцсети — локально (`prepare-post.ts` + `npm run publish`, см. план деплоя
`docs/plan-deploy.md`).

## Типы контента

| Команда                      | Что создаёт                             |
| ---------------------------- | --------------------------------------- |
| `npm run new post <slug>`    | короткий пост (twitter/telegram-формат) |
| `npm run new article <slug>` | большую статью с `<!--more-->`          |

`slug` — только `a-z0-9` и дефисы (`my-first-post`). Папка с таким именем не
должна существовать.

## Что происходит при создании

Визард сразу создаёт пару файлов:

```txt
src/content/posts/<slug>/
  index.ru.md        # основная версия, пишем здесь
  index.en.md        # авто-копия с needs_translation: true
```

```txt
src/content/articles/<slug>/
  index.ru.md
  index.en.md
```

- язык определяется именем файла — поле `lang` в frontmatter не нужно и линтером
  запрещено;
- `index.en.md` — заглушка с `needs_translation: true`; перевели — поставьте
  `needs_translation: false` либо удалите поле;
- создать `index.en.md` для уже существующей единицы:
  `npm run sync <post|article> <slug>`;
- без перевода ничего не ломается: en-версия на сайте показывает заглушку, в
  списках — одна карточка.

## Frontmatter

```yaml
---
title: My first post
date: 2026-09-15 # ISO YYYY-MM-DD, обязательно
tags: # массив строк, необязательно
  - svelte
  - js
image: images/cover.jpg # опционально, путь относительно папки единицы
link: https://example.com # опционально, только у постов
draft: true # опционально: черновик
---
```

- у статей тизер — текст до `<!--more-->` (маркер обязателен, визард вставляет
  сразу);
- у постов весь текст идёт целиком и на сайт, и в соцсети, `<!--more-->` не
  используется;
- черновик: `draft: true` — на сайт (в production) и в автопостинг не попадает,
  в dev виден с бейджем;
- даты — строго ISO `YYYY-MM-DD` (иначе линтер ругается).

## Проверка локально

```bash
npm run lint:content   # валидация всех единиц src/content/*
npm run dev            # предпросмотр (черновики видны)
```

## Что происходит после пуша

1. Пуш в `main` запускает `deploy.yml` — сайт пересобирается на GitHub Pages.
2. Автопостинг — локально: `prepare-post.ts` по переменной `FILES` (обрабатывает
   только `index.ru.md`, пропускает черновики) → `npm run publish` (Telegram и
   Discord). Повторный запуск того же поста правит существующее сообщение, а не
   дублирует.

## Правила

- язык — только из имени файла; `needs_translation` — только в `index.en.md`;
- у статей обязательно `<!--more-->`, у постов — нет;
- готовый пост в автопостинг не попадает только из-за `draft: true` — снимите
  флаг и запушите.
