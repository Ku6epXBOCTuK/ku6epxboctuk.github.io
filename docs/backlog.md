# Backlog

Вопросы закрыты и зафиксированы в планах (см. `docs/plan-content-model.md`, блок
«Решения по вопросам из беклога»).

- [x] **Тизер статей из `<!--more-->` и readingTime нельзя получить из
      module-глоба** — решено: параллельный `?raw`-глоб (`import.meta.glob` с
      `query: "?raw"`, стандартная фича Vite) отдаёт raw-тело; тизер — обрезка
      по `<!--more-->`, readingTime — слова/200. Поле во frontmatter не вводим.
- [x] **Английская версия для всех типов контента** — решено: двуязычность всех
      типов (статьи/посты сейчас, проекты/weekly на этапе 2). `index.en.md` —
      автоматическая копия с `needs_translation: true`, создаётся сразу при
      создании основной версии (отдельного шага «создать файл перевода» нет).
- [x] **Хранение: папка на каждую единицу с `index.ru.md`/`index.en.md`** —
      решено: `src/content/<type>/<slug>/index.<lang>.md`. Slug = имя папки
      (уникальность по построению); для weekly — ISO-дата понедельника.
