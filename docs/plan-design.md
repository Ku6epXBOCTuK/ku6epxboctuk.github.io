# Дизайн: layout personal-blog + кожа kawaii.os

> Статус: на ревью. Один из трёх планов: дизайн, модель контента, автоматизация.
> Подход: не изобретаем структуру — берём layout и карточки из прототипа
> `refs/personal-blog` (Next.js), а цветовую тему, шрифты и «окошки» — из
> `refs/new_design` (kawaii.os). Согласовано по итогам ревью: терминальная тема
> старого сайта и GitHub-сетка не переносятся, Twitch API убран.

## Решено по итогам ревью

Открытые вопросы из прошлой версии закрыты:

1. **kawaii.os-акценты** (глобус, облачка, звёздочки с анимацией в hero и на
   фоне) — из MVP вычеркнуты; layout чистый, декор вернуть точечно при желании.
2. **Реакции ♥ у постов — убраны.** В схеме постов их нет, а статический сайт
   без бэкенда не умеет клики. Мета-строка поста: дата + теги.
3. **Бейдж статуса проекта** — один нейтральный бейдж (`active`/`maintained`/
   `archived`); цвета (`coral`/`periwinkle`/`sky`) остаются иконке проекта.

## База: layout из refs/personal-blog

Прототип живёт в `refs/personal-blog` — Next.js + Tailwind, chill-блог с мягкой
палитрой. Оттуда берётся скелет (переносится на Svelte один в один по
структуре):

| Блок прототипа | Что это                                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------------------ |
| Topbar         | логотип `xboct.dev`, ссылки (home / posts / articles / projects / weekly), справа ThemeToggle                |
| Hero           | слева приветствие: eyebrow, крупный заголовок, абзац, две кнопки; справа декоративный блок-«окошко»          |
| Секции         | заголовок секции + ссылка «смотреть все» справа; сетка карточек 2 колонки (мобайл — 1)                       |
| Card           | картинка сверху (скруглена, «залита» в окно), body: meta-строка, заголовок, абзац, низ: теги + значок-кнопка |
| Footer         | строка бренда + сноска                                                                                       |
| Страницы       | списки и детальные: ширина читалки, заголовок, meta-строка, контент                                          |

Анатомия карточки и «дыхание» секций сохраняются; меняется только кожа (ниже).
Карточки: PostCard / ArticleCard / ProjectCard / ReportCard — один каркас,
различаются meta-строкой и низом:

- пост — дата, теги;
- статья — дата, время чтения (`readingTime` из body), теги;
- проект — опциональная обложка (`image`), иконка (эмодзи `icon` + акцент
  `color` из projects.yaml, см. планы контента и автоматизации), бейдж статуса,
  ссылки исходники / demo;
- weekly — простая карточка (без тайтлбара): строка-дата с иконкой 📅 (цвет
  ссылки), список строк «проект → изменения» (проект жирный 13px, минимальная
  ширина 110px; изменения 14px приглушённые; разделитель — 1px `--line`), внизу
  text-link «открыть отчёт»;

## Кожа: палитра и шрифты из refs/new_design (kawaii.os)

Kawaii.os — ref-прототип в стиле «милой ОС»: окна с тайтлбаром, жёсткие тени,
пастель. Смотреть `refs/new_design/style.css` (токены там уже на oklch).

Решение по разделителям: используем `--line` (светлее kawaii-обводки — 2px
коричневая `--outline` вокруг всего подряд шумит).

Шрифты через `@fontsource` (оффлайн-сборка, никаких Google Fonts CDN):

- `@fontsource/comfortaa` (400/600/700) — display: заголовки, кнопки, бейджи;
- `@fontsource/nunito` (400/600/700/800) — body.

Правило AGENTS.md соблюдается: все цвета только через переменные `src/app.css`.

### Сигнатурные приёмы kawaii.os

- **Карточки-«окошки»**: 2px обводка (в kawaii.os — градиентная `outline` +
  `periwinkle` через `border: 2px transparent` + двойной `background` с
  `padding-box/border-box`), скругление 14px, жёсткая тень `3px 3px 0`, без
  размытия.
- **Тайтлбар** у декоративных окон (hero-виджет, weekly): фон `--titlebar`, три
  точки-«светофора», системный текст.
- **Кнопки**: primary — заливка `--primary` + `--hard-shadow`; ghost — обводка
  `--outline`. Hover — сдвиг `translateY(-1px)`.
- **Чипы** (телефон/дискорд в hero): kawaii-чип `2px var(--outline)` +
  скругление 8px.
- Радиусы: карточки 14px, иконки/кнопки 10px, чипы/теги 8px.

## Темы: два скина × светлая/тёмная = 4 варианта

Решено на ревью превью: реализуем оба скина с одинаковым набором имён
переменных, выбор — после реализации главной страницы (оставить один или все
варианты). Layout, карточки и страницы общие, переключается только набор
переменных плюс несколько точечных переопределений там, где различается сама
техника (бордер карточки, тени, радиусы, шрифты).

- `kawaii` — палитра/шрифты/жёсткие тени из `refs/new_design` (раздел выше);
- `soft` — палитра из `refs/personal-blog/app/globals.css`, Arial, мягкие
  размытые тени, тонкие 1px-границы вместо обводок.

Механика: `data-skin="kawaii|soft"` на `<html>` + класс `dark`. Селекторы:
`[data-skin="kawaii"]`, `[data-skin="kawaii"].dark`, `[data-skin="soft"]`,
`[data-skin="soft"].dark`. Переключатель в топбаре: пара чипов (скин) + чип ☀/☾
(режим). Выбор хранится в `localStorage` (`skin`, `theme`), инлайн-скрипт до
отрисовки выставляет оба атрибута — без FOUC, дефолт kawaii + light.

компонентах по скину.

## Кастом

- **Тема и скин** — механика описана в разделе «Темы»: инлайн-скрипт до
  отрисовки выставляет `data-skin` + `dark`, в топбаре две квадратные
  кнопки-иконки (36×36, стиль чипа): переключатель скина — показывает иконку
  скина, на который переключишься (🎀 милая / `</>` техническая, моноширинный),
  и кнопка режима — только ☀/☾ без надписей. Подсказки через `title`. Всё
  хранится в `localStorage`, дефолт — kawaii + light.
- **Focus-visible**: глобально
  `outline: 2px solid var(--coral); outline-offset: 2px`.
- **Чипы telegram/discord** в hero под кнопками (Twitch API из старого макета не
  переносим — только статичные ссылки-чипы).
- **Терминальный виджет** в hero («окошко» с тайтлбаром): строки `whoami`,
  `current_mood`, `now_playing`; статус «сейчас: …» — источник остаётся прежним
  (ручное поле/конфиг), оформление — kawaii-окно.
- **Кнопки спонсоров**: Donation Alerts / CloudTips / Boosty — в футере и на
  странице «про меня»; стиль ghost-кнопок с иконками сервисов.
- **`readingTime`** у статей: считаем из body при сборке (слова / 200),
  показываем в meta-строке ArticleCard и на детальной странице.

## Порядок внедрения

1. Токены в `src/app.css` (4 набора: kawaii/soft × light/dark + композитные),
   шрифты `@fontsource` (Comfortaa+Nunito; Arial системный), инлайн-скрипт
   (`data-skin` + `dark`) и `ThemeToggle.svelte` (две кнопки-иконки: скин
   🎀/`</>` и режим ☀/☾).
2. Каркас: `Topbar`, `Footer`, hero + терминальное окно, контейнер 1120px.
3. Карточки: общий каркас `Card` + `PostCard` / `ArticleCard` / `ProjectCard` /
   `ReportCard`, страницы списков и детальные.
4. Мелочи: focus-visible, чипы telegram/discord, спонсоры, readingTime,
   полировка мобайл-версии.

Проверки после каждого шага: `npm run format` → `check` → `lint`.
