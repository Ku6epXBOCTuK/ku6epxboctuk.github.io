Сборка, деплой и скорость: что реально важно для личного сайта без бэкенда.

<!--more-->

## Сборка

SvelteKit в режиме static-pages, всё дерево контента — в eager-глобах при
сборке.

## Деплой

GitHub Actions пушит в ветку pages. Триггер — по изменению контента.

## Скорость

Ноль бандла JS на листингах, шрифты оффлайн через @fontsource.
