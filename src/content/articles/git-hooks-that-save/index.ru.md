Форматтер, линтер и проверка сообщений коммитов — три хука вместо утренней
рутины ревью.

<!--more-->

## pre-commit

Формат и лёгкий линт только изменённых файлов.

## commit-msg

Конвенция сообщений: тип + модуль. Опечатка — коммит отклонён.

## pre-push

Полный check. Если сломалось на last device — пуш не уйдёт.
